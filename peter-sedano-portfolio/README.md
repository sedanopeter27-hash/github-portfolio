# Peter Sedano — Portfolio

Responsive multi-page portfolio built with HTML, CSS, and JavaScript.

## Pages
- Home
- About
- Projects
- Skills
- Contact

## Features
- Dark/light monochrome theme; preference is saved locally
- Click the home profile photo to switch themes
- Welcome screen shown whenever the home page is opened
- Custom local SVG illustrations for AgriConnect and AuraGuard AI
- Animated Tanjiro-inspired chibi decoration on the home page
- Subtle hover, tap, and card interactions
- Responsive mobile navigation
- Email, Facebook, and GitHub contact links with icons
- Reduced-motion support

## Run locally
Open `index.html` in a browser or use VS Code Live Server.

## Profile photo setup
- `assets/images/peter.jpg` is the existing dark-mode portrait.
- The code is configured to use `assets/images/peter-light.jpg` in light mode.
- The separate light-mode photo was not present in the ZIP available for this update. Add the photo you supplied earlier using exactly that filename to enable the intended photo switch. Until then, the site safely falls back to `peter.jpg`.

## Publish with GitHub Pages
Upload the contents of this folder to your existing repository, keeping the same folder structure. Test locally first and publish when ready. No deployment has been performed by this update.



### Project artwork
Custom SVG illustrations are included for AgriConnect, ACE-CCT EventSync, Arduino / ESP32 prototypes, Automatic Gravy Dispenser, AuraGuard AI, and the personal portfolio. Replace these illustrations with your own project screenshots or photos whenever you have them.
