# Peter Sedano — Portfolio

A responsive, multi-page portfolio built with HTML, CSS, and JavaScript.

## Pages
- Home
- About Me
- Projects
- Skills
- Contact

## Features
- Dark cinematic monochrome design
- Responsive navigation for mobile and desktop
- Click the home-page profile photo or the theme button to switch between dark and light mode
- Theme preference is saved in the browser when local storage is available
- Reduced-motion support
- Contact links for email, Facebook, and GitHub

## Run locally
Open `index.html` in your browser, or use a local server such as VS Code Live Server.

## Publish with GitHub Pages
1. Create a public repository named `sedanopeter27-hash.github.io`.
2. Upload the contents of this folder to the repository root (not the parent folder).
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/(root)`, and save.
5. Wait for the deployment, then visit `https://sedanopeter27-hash.github.io`.

Before publishing, review every project description and status so it accurately reflects your work. The profile photo is stored at `assets/images/peter.jpg`.
